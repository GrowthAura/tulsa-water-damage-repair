## 5 + 6. Dangling "See and" / dangling "see" cuts (sitewide)

**Rule (his order):** cut a "See" or "see" ONLY when it DANGLES — it ends a bullet/paragraph/sentence with no continuation after it. A "See/see" that is part of a real sentence stays untouched.

**Origin:** the earlier "See"-unlinking round removed 278 "See" anchors but kept the words, leaving paragraphs ending in a bare "See". The doc writes "Phrase (/path)"; the parser made "See" the anchor for a parenthetical path, and unlinking left the word dangling.

**What was cut (240 dangling See/see words removed, 47 pages touched):**
- **18× "See and" (anchored):** `See  <a>and</a>` at the end of a paragraph → removed the whole fragment; the sentence ends cleanly at its period.
- **8× "See and" (plain text):** `See  and` with an unlinked "and" — found only by the re-verification pass (the first classifier matched only `<a>and</a>`). Same cut.
- **208× dangling "See"** at the end of a paragraph / bullet / FAQ answer / table cell → removed the trailing " See".
- **1× burst-pipe block 31 (special, 2 words):** `<strong>For <a>ceiling damage</a> from attic bursts:</strong> see <br><a><strong>For hardwood floors:</strong> see</a>` → both "see"s cut; renders as two clean lines, both links intact.
- **1× sewage bullet (special):** the bullet is a link whose text was `Basement backups: see` → became `Basement backups` (the colon went with the "see" — it only introduced the removed reference; link target unchanged).
- **3× "See"-only blocks removed:** `/resources/how-to-file-water-damage-insurance-claim-tulsa` block 7, `/resources/oklahoma-water-damage-insurance-guide` block 27, `/resources/water-damage-vs-flood-damage-insurance-oklahoma` block 21 — each block's ONLY content was the word "See", so the empty block was removed (no real content in it).
- **42× FAQ `a_text` mirror cuts:** the first pass only cut `a_html` (visible), leaving the FAQPage schema field `a_text` still ending in "See" on 42 answers (visible != schema). Fixed in `tools/fix_faq_atext.py` — see §9.

- **Real-sentence "See"s everywhere else** (e.g. homepage "See every service organized in one place on our hub page.", "See our insurance claim guide:") — part of a real sentence, untouched.
