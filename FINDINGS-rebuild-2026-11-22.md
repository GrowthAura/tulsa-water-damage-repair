## 4. DESIGN DECISIONS (decided at end-level — no veto windows)
### 4.1 Palette — keep the brand water, deepen it for the $50k feel
- Keep navy #073B66 / blue #0056A3 / cyan #00BFFF / cream #F7F3EA as the brand core (recognition + trust). Deepen: add a richer deep-navy #062A4A for hero scrims, footer depth, and premium bands; add a soft mist blue-grey #EAF2F7 for alternating section washes (cooler and more premium than flat white). Cyan stays the electric emergency accent — used sparingly (CTAs, live dots, rules) so it keeps its punch.

- Contrast: every text/background pair AA (4.5:1 body, 3:1 large), measured, not eyeballed.

### 4.2 Typography — two-face system
- Body/UI: DM Sans (400/500/700) — kept, it is clean and fast.
- Headings: **Fraunces (display serif, 600–700, tight tracking)** for H1 + H2. This is the out-of-the-box move: every competitor restoration site uses a grotesque; an editorial serif reads premium, trustworthy, and unmistakably NOT a template. H3 stays DM Sans 700 blue (functional hierarchy: serif = authority, sans = action).
- FALLBACK RULE: if real screenshots show the serif reading soft, old-fashioned, or wrong for an emergency service, revert headings to DM Sans 800 and log the revert with screenshot evidence. The eye decides, not the theory.
- Type scale (desktop): H1 clamp(2.75rem, 6vw, 4.5rem), tight leading 1.0, -0.03em; H2 clamp(2rem, 3.6vw, 3.25rem), leading 1.05; H3 clamp(1.4rem, 2.2vw, 1.9rem). Mobile: H1 ≥2.1rem, never wraps mid-phrase awkwardly; H2 never orphans a single short word (balance + max-width guards where needed).
- Body 18px / 1.75. Lead/intro 20–23px. Wide lines: container 76rem → **80rem (1280px)**; hero H1 + intro span the full container; content column widened (split 8fr/4fr kept, gap 3rem → 3.5rem).
