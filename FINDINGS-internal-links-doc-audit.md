## Method (why the anchors were giant)

The doc writes "Phrase (/path)". The original parser split sentences at parentheticals and made each segment the anchor for the following path, so the whole sentence start up to the first parenthetical became one giant anchor. Bare "See (/path)" parentheticals produced "See" anchors (unlinked in the earlier See round) and leftover "and" anchors from "See (/path) and (/path)". One doc parenthetical sometimes produced TWO `<a>` tags in one block (split pairs). All fixes below follow the doc parentheticals: the target never changes, only the anchor span narrows (or unlinks when no real <=5-word anchor exists in the span). No visible words were changed except the one sanctioned slab-leak sentence.
